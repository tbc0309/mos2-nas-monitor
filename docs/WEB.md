# 网页在线刷写

**[网页在线刷写](https://tbc0309.github.io/mos2-nas-monitor/)**

电脑使用 Chrome 或 Edge，通过 USB 数据线连接 MOS2，关闭占用串口的软件，选择对应串口并按提示安装。网页根据浏览器语言显示中文或英文，可手动切换；刷写工具原生对话框为英文。

完整安装会覆盖配置、照片和字库。保留数据升级请使用设备后台「维护 → 固件升级」。

安装后加入 MOS2-NAS-xxxxxx 热点（密码 12345678），打开 http://192.168.4.1/ 配置 2.4GHz Wi-Fi。联网后五击屏幕显示管理二维码，首次管理登录必须修改默认密码。
