# Online installation

**[Online firmware installer](https://tbc0309.github.io/mos2-nas-monitor/)**

Use desktop Chrome or Edge and a USB data cable. Select the MOS2 serial port and follow the installation prompts. The initial language follows the browser: Chinese variants use Chinese, all others use English. You can switch at the top. Native installation dialogs are in English.

A full installation overwrites settings, photos and fonts. To keep data, use the device management page: Maintenance → Firmware update.

After installation, join MOS2-NAS-xxxxxx (password 12345678), open http://192.168.4.1/ and configure 2.4GHz Wi-Fi. Tap five times for the management QR code. Change the default management password on first login.
