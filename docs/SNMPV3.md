# SNMP v3

后台 NAS 设置可选择 v2c 或 v3。v3 认证支持 MD5、SHA（SHA-1）；隐私加密可选不加密、DES、AES（AES-128 CFB128）。支持 MD5 + DES、MD5 + AES、SHA + DES、SHA + AES 四种组合。

群晖与MOS2须使用相同用户名、认证协议和认证密码；启用隐私时，双方使用相同隐私协议及密码。认证与隐私密码可以不同，分别留空保留已有值，长度为 8–64 字节。用户名最多 32 字节。v2c 使用 community。

两种认证均校验完整报文的 HMAC-96、引擎标识和时间窗。隐私密钥使用对应认证算法独立本地化。DES 使用 CBC、8 字节盐；AES 使用 128 位 CFB、64 位递增盐及引擎启动计数/时间构造 IV。先认证再解密，拒绝明文降级响应。固件使用 BearSSL，模拟器使用 PyCryptodome。网页和状态 API 不返回认证、隐私及管理密码。

设备状态显示 SNMPv2c / SNMPv3。启用隐私时，总览显示绿色锁标，与内存卡片右缘对齐；旁边的状态圆点独立显示连接状态。锁标表示配置了加密，连接是否正常以采集状态为准。

实现参照 [RFC 3414](https://www.rfc-editor.org/rfc/rfc3414) 和 [RFC 3826](https://www.rfc-editor.org/rfc/rfc3826)。测试覆盖 MD5/SHA 密钥向量、DES/AES 标准向量、四种加密组合、独立隐私密码、唯一盐、篡改/截断/时间窗/拒绝降级，以及改密、退出登录和中英文六页分块绘制一致性。SHA + AES、MD5 + AES、SHA + DES 已通过真实 NAS 与实体机实测。
