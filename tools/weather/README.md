# 中国天气字集

到省、市级天气地点，375条。地点快照来自 https://j.i8tq.com/weather2020/search/city.js ，提取各城市同名地点的 AREAID，所有条目均存在精确名称匹配，没有用首项代替。含港澳台。并非行政区划权威目录。

天气名称依据 https://www.weather.com.cn/forecast/legend.shtml ，补充雾霾等级、组合词及常见描述。采集日期2026-10-11。数据用于构建字库和浏览器选择，不在ESP运行时下载整个目录。

## 风向和风力

wind.json覆盖16方位、无持续风向、偏向、阵风、0至17级和范围及单位。天气API的WD、WS及英文wde、wse均显示，需要独立覆盖。2026-10-11实测天津、北京、深圳、乌鲁木齐均返回1级；增加整行文本回归检查，而不只检查weather字段。天气现象扩展核对 https://hainan.weather.com.cn/zt/zt2019new/3299096.shtml 。

## 自定义地点

内置375个市级地点在中文界面显示中文，英文界面显示接口nameen。自定义国内县区地点在两种界面都显示接口nameen（通常为拼音）；缺少名称时显示Weather。超长名称固定字号往返滚动。

保存前通过/api/weather/check校验。内置目录和未修改代码直接通过；新自定义地点异步查询，10分钟缓存成功结果，后台/save再次检查，未验证代码不落盘。超时或服务错误提示重试，不当成代码不存在。国外fc预报明确提示暂不支持实时天气，不伪造温湿度。
